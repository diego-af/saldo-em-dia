# Distribuir o aplicativo para Linux e Windows com dados locais

O gestor financeiro terá instaladores para Linux e Windows, manterá seus dados localmente em cada instalação e confiará na sessão autenticada do sistema operacional em vez de exigir uma senha própria. Não haverá sincronização automática entre computadores na primeira versão; essa escolha preserva simplicidade e privacidade sem limitar a instalação a um único sistema.
