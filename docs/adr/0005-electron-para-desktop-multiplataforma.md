# Usar Electron para o aplicativo desktop

O aplicativo será construído com Electron para gerar instaladores para Linux e Windows e oferecer inicialização automática, execução em segundo plano e notificações nativas. A escolha prioriza a cadeia Node.js já disponível e menor complexidade de desenvolvimento, aceitando instaladores maiores e maior consumo de memória em comparação com Tauri e Rust.
